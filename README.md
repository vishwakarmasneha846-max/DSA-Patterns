# Java DSA Pattern Programs

This repository contains Java implementations of common DSA pattern-printing problems. These programs are useful for beginners to practice nested loops and strengthen programming fundamentals.

## Patterns Included

- Solid Square
- Solid Rectangle
- Hollow Rectangle
- Half Pyramid
- Numbered Half Pyramid
- Rotated Half Pyramid
- Inverted Half Pyramid
- Inverted Numbered Half Pyramid
- Floyd's Triangle
- Binary Pyramid (0-1 Triangle)
- Butterfly Pattern

## Language

- Java

## How to Run

1. Compile the program:

```bash
javac ButterflyPattern.java
```

2. Run the program:

```bash
java ButterflyPattern
```

Replace `ButterflyPattern` with the name of any other Java file you want to run.
